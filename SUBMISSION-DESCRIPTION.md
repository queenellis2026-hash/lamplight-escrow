# DoraHacks Arc Microgrants — Submission Description

**Lamplight Escrow v2** — pay-on-delivery escrow for AI agents on Arc. The requester locks USDC in a contract; the agent proves delivery on-chain; only then does the money move. V2 adds an optional per-escrow arbiter who resolves disputed deliveries.

Built end-to-end in Arc Studio from a plain-language description — contract, 168 tests, and the working app. Verified byte-identical before mainnet deploy.
